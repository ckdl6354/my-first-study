## 1. 가위바위보 문제
* 성능저하를 막기 위해 StringBuilder를 사용 반복문(for)으로 rsp 문자열의 길이만큼 반복한다.
* current라는 문자형 변수선언하고 rsp.charAt(i)를 하나씩 넣는다.
* switch문으로 current값을 기준으로 '2'(가위)일때 바위로이겨야하므로"0"을반환
* '0'(바위)일때 보로 이겨야 하므로 "5"반환,'5'(보)일때 가위로 이겨야 하므로 "2"반환
* return을 통해 돌려주는값을 toString으로 문자열로 변환해서 반환한다.
* **주의할 점** StringBuilder는 String과 다른타입이므로 마지막에 .toString()을 붙여서
문자열로변환후 내보내야한다

## 2.글자 이어 붙이기 문제
* StringBuilder를 사용하고 for(each)문을 사용하여 int idx를 index_list를 순서대로 하나씩 출력
* answer.append(my_string.charAt(idx)); = answer의 끝문자열을 my_string.charAt(idx) 하나씩붙인다
* return answer.toString(); = 문자열 변환 후 출력

## 3. 숫자 9로 나눈 나머지 문제
* int sum 변수를 0으로 초기화하고 반복문(for)문을통해 number길이만큼 반복한다.
* sum변수에 number.charAt(i) - '0'; 문자열 하나씩 sum에 (누적)더한다.
* 반환값으로 sum에 나눈 나머지 9를 반환
