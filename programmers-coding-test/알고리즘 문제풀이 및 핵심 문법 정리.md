## 10.원소들의 곱과 합(쉬움)

* 반복문(for(int i=0;i<num_list.length;i++)) // i가 0부터 시작해 num_list길이만큼 반복한다.
* sum+= num_list[i]; //sum이라는 변수에 num_list[i]를 0부터 더해서 채워넣는다.
* product *= num_list[i] //product라는 변수에 num_list[i]를 곱해서 넣는다.
* 만약(if) product가 sum*sum보다 작거나 같을때  return 1; 1을반환
